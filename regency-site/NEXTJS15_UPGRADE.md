# Next.js 15 Upgrade - MacDonald Highlands Luxury Real Estate

## ✅ Upgraded to Next.js 15

This project has been upgraded to **Next.js 15.1.0** with **React 19** and modern luxury real estate design best practices.

## 🎨 Luxury Design System

### Typography
- **Sans-serif**: Inter (body text, UI elements)
- **Serif**: Playfair Display (headings, luxury accents)
- Optimized font loading with `display: swap`

### Color Palette
- **Primary**: Indigo (trust, sophistication)
- **Accent**: Emerald (growth, luxury)
- **Gold**: Amber (premium, exclusivity)
- **Neutrals**: Refined grayscale palette

### Design Tokens
- Luxury spacing scale (xs to 4xl)
- Premium shadow system (sm to 2xl)
- Smooth transitions (fast, base, slow)
- Custom animations (fade-in, slide-up, slide-down)
